## 1. 标识与链接完整性

1. 主键为交付伪标识 `id`（12 位大写哈希，数据方交付前生成；已核实非身份证号原始值）。
2. H 库身份证校验和（GB11643-1999）验证：30,676/30,677 通过（1 例 15 位旧式），结果仅以
   `id_integrity` 标记入库；**原始证件号与映射表不入仓库**。
3. 年龄-出生年一致性：偏差 >3 岁的行计数入报告（H 库现况 4 行，0.003%）。
4. 人-波唯一性：同人同年多报告 → 保留关键完整性最高、日期最早的一条（PD 记录去重
   −17,228 行；PG 人-年聚合 129,953→71,209）。

### 1.1 单一键体系（2026-09-14 新增，强制）

- **全项目仅允许两套人员标识**：H 平台伪标识（`mapping_H_idcard.pseudo_id`）与
  PG 平台伪标识（PG 库 `id`）。二者体系独立，跨库不按 id 链接。
- **任何文件（含论文派生表、标注工作簿、待标注集、投稿材料）不得出现身份证号原文**；
  需要人员标识时一律使用上述平台伪标识，或使用论文内部的样本身份 `sample_id`。
- **禁止自造第三套哈希**（历史上曾因标注工作簿使用另一套盐值伪标识，导致与清洗层
  无法对齐；2026-09-14 已统一，见 论文01 审计记录）。
- 审计方式：全目录扫描「GB11643 校验和通过的 18 位串」与「非平台体系伪标识」，
  两者均须为 0 处。
- PII 类报告（扫描命中台账等）自身亦须脱敏：标识列用伪标识，命中串掩码化。

### 1.2 文本层 PII 掩码（2026-09-14 新增，2026-09-14 扩至全库，强制）

- 自由文本（超声结论、主检结论、心电描述等）由院方录入，**可能内嵌非临床号码串**
  （例：`T13800138000`，此处为合成示例）。此类内容不是"可清洗的脏数据"，
  而是**必须掩码的 PII**。
- **处置范围（全库）**：所有载有中文自由文本的**数据层**载体（`.csv`/`.csv.gz`/`.tsv`/`.xlsx`）；
  文档层（`.md`/`.docx`/`.txt`）**只报告不改写**（其中的长数字多为基金号、统计量或示例引用，
  就地掩码会破坏文本；如文档内出现真实 PII，按 §1.1 与人工政策单独处置）。
- **掩码判定（防误伤，2026-09-14 三轮回溯校准）**：
  1. 「**同一单元格内**与中文相邻的 7+ 位号码串」（不跨 `,` `;` `"` 制表符 `|`）
     —— 例 `T13800138000肝`；结构化键列/条码/哈希/浮点小数因邻居非中文而天然不匹配；
  2. 「英文前缀 + 11 位手机号格式且紧邻中文」—— 例 `：T13800138000肝`；
  3. 座机（`0xx-xxxxxxx`）。
  - `YYYYMMDD[hhmmss]` 形态日期时间戳跳过；替换统一为 `[REDACTED]`（不保留原长度）。
- **不掩码、仅报告**：作者/机构邮箱（投稿信与正文中的正常业务内容）、姓名、住址、
  裸手机号/裸身份证号列（结构化标识，见 §1.1 与下方"已知残留"）。
- **跳过**：`PG/raw_mirror` 中 >30 MB 的原始化验/检测/问卷表（无临床自由叙述文本；
  人员标识由 §1.1 负责，已由 B17/B18 归零），跳过清单在报告中登记。
- **阳性对照自检**：脚本内置已知残留形态（`T18071500010肝…`、`…。 T18063000080`），
  自检不通过即中止，禁止在错误口径下出报告。
- **审计要求**：掩码后复扫须为 **0 命中**（可掩码型）；流程脚本化
  （`B19`/`B20`/`B25`：扫描 → 掩码 → 复扫），报告与掩码日志随 `results/` 留档，
  原件备份至 `归档/全库文本PII掩码前_<日期>/`。
- **实现口径（2026-09-14 两轮返工后固化，勿再改回）**：
  1. 编码一律按 **UTF-8（BOM 容忍）+ surrogateescape 无损往返**；**禁止**"严格解失败即回退 GBK"
     的猜测式探测——它会把 UTF-8 中文解成乱码，导致中文邻接判定失效（漏掩码）且写回后文件被乱码覆盖；
  2. 扫描阶段可用字节前置筛加速，**掩码阶段必须逐行无筛**（前置筛会漏行）；
  3. 就地掩码一律**字节级正则（不解码）**，单元格分隔符须含 `\r` `\n`（CSV 引号字段内可含裸 `\r` 记录边界）；
  4. 写后必须**自验**（对已写文件复扫，`post_hits` 必须为 0）并留计数。

**已知残留（登记为待决策项，2026-09-14）**：`data/H/raw_mirror` 保留了数据方交付的
**结构化标识列**（姓名、电话、住址；例 H_2020 含 828 条住址记录）。该类镜像层为
**受控隔离副本、永不外发**，分析层（wave/person level）与论文派生表**不含**这些列；
是否在镜像层就地清空这些列，需数据提供方口径确认后决定（不影响任何已发布统计量）。


## 2. 数值抽取与单位规则

1. 带单位文本（PD 库）按字段正则抽取首个数值，含 ↑/↓ 修正。
2. 项目名映射必须以库内 DISTINCT 项目名实测为准（教训：PG 主血糖项名为"葡萄糖"而非
   "空腹葡萄糖"，ALT 为"丙氨酸氨基转移酶"；旧提取漏抓导致 FPG 假缺失 70,180 条）。
3. 单位以库内多数口径为准；发现混合单位（如 UA 的 mg/dL 残留、2022 尿 pH 混入 FPG）一律
   **置缺失**，不做自动换算，除非有明确换算依据并写入报告。

## 3. 列移位（错行错列）防护

1. 任何年度文件新增/变更模板时，必须做**行级移位签名扫描**：
   通用签名包括 `bun>25 & ua<90`（肝肾互换）、`sbp<dbp`、`hdl>tc`、`ldl>tc`、
   `fpg 落在尿 pH 带且方差异常`、`corr(alt,ast) 异常`、`corr(tg,hdl) 转正` 等。
2. 跨年分布审计：全数值字段逐年中位数对比，偏离 >25% 告警（v1.0 仅 CEA/CA199 平台差异，
   非分析变量）。
3. 移位修复必须以**原始文件逐列重提取**为准（H 库 2022 案例：缺"谷丙转氨酶"列模板致
   整行左移一位，波及 12 个生化字段 + 心电/超声文本；修复经非移位行判读一致性验证）。

## 5. 跨字段一致性修复（先审计后修复，全部落计数）

1. `sbp<dbp` → 双置缺失（H 130 行、PD 52 行）。
2. `|bmi − 体重/身高²| > 2.5` → 用身高体重重算；重算越界则置缺（H 33、PD 206 行）。
3. `hdl>tc` / `ldl>tc` → 相应字段置缺（HDL: H 4、PD 38、PG 0；LDL: H 14、PD 962）。
4. `fpg<3.0` → 置缺（社区筛查场景不可信，H 14、PD 2,061、PG 1）。
5. `ua<120`（疑似 mg/dL）→ 置缺（H 131、PD 325、PG 35）。
6. `tg>25`、`crea<20`、`plt>800`、`hb<60`、`wbc>25`、`alt>1500`、`ast>1500` → 置缺
   （v1.1 起 PD 同步落地：PD crea<20 1,661、alt/ast>1500 1；H tg>25 5、crea<20 6、
   plt>800 6、hb<60 17、wbc>25 15、alt/ast 3；PD tg>25 33；PG tg>25 45、crea<20 4）。
7. 修复完成后**重算**所有依赖字段（dm_screen/htn_screen 等），并重建分析层。

## 6. 标准衍生层（L2，统一临床定义）

- `dm_screen` = FPG≥7.0 或 HbA1c≥6.5（PD 并入病史"糖尿病"）；双缺失置 NA。
- `htn_screen` = SBP≥140 或 DBP≥90（PD 并入病史"高血压"）。
- `dysglycemia` = FPG≥5.6 或 HbA1c≥5.7。
- `central_obese` = 腰围男≥90/女≥85（PD 含 BMI≥28 兜底）。
- `high_tg` = TG≥1.7；`low_hdl` = 男<1.0 / 女<1.3。
- `steatosis_cmrf` = 超声脂肪肝 ∧ ≥1 心代谢组分（2023 MASLD 近似；**仅限具备全部组分
  测量的库**：H 可算；PG 无血压/腰围 → 不算；PD 论文层按需构建）。
- 指数：CKD-EPI 2021 eGFR、TyG、FIB-4、HSI、SII（公式与原管线一致）。
- B超词典：H explicit=含"脂肪肝"（2020 波经描述式规则补丁恢复）；PG/PD
  explicit ∪ 描述性声像词（细密/弥漫/衰减等）双口径。

## 7. 已知局限（随库披露）

1. H 库 HbA1c 仅 2018/2024 少量选择性检测（2,455 波），糖尿病判定实际由 FPG 驱动。
2. PG 库无体格/血压规模数据；"葡萄糖"假定为空腹口径（与 OGTT 各时点项分列，分布
   中位 5.55 mmol/L 支持）。
3. PD 库为全年龄体检人群，老年亚组限定（≥60）由论文层声明；病史字段为文本，依赖
   "糖尿病/高血压"关键词。
4. H 库 ECG 文本 6 行残留超声关键词（2022 移位修复未匹配行），已置缺处理。
